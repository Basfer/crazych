# 🐔 Crazy Duck

HTML5 Canvas और Vanilla JavaScript के साथ बनाया गया ब्राउज़र-आधारित "बतख शिकार" गेम।

## 🎮 कैसे खेलें

1. किसी भी आधुनिक ब्राउज़र में `index.html` खोलें
2. **"खेल शुरू करें"** पर क्लिक करें
3. माउस से निशाना लगाएं और बाएं बटन से गोली चलाएं
4. 90 सेकंड में अधिकतम अंक प्राप्त करें!

## 🎯 लक्ष्य के प्रकार

| प्रकार | अंक | विवरण |
|--------|-----|--------|
| 🐔 सामान्य | 10 | धीरे से सीधा उड़ता है |
| ⚡ तेज | 20 | तेजी से, ज़िगज़ैग उड़ता है |
| 🪂 गिरने वाला | 30 | ऊपर से पैराशूट के साथ गिरता है |
| 🛸 यूएफओ | 50 | बहुत तेजी से उड़ता है |

## 🎮 नियंत्रण

- **माउस** — निशाना
- **बायाँ बटन** — गोली चलाएं

## 📋 गेम सेटिंग्स

- **राउंड का समय:** 90 सेकंड
- **गोला-बारूद:** 60 गोलियां
- **लक्ष्य:** अधिकतम अंक प्राप्त करें

## 🛠️ तकनीकें

- HTML5 Canvas
- Vanilla JavaScript (ES6+)
- Web Audio API (संश्लेषित ध्वनियां)
- CSS3
- Supabase (ऑनलाइन लीडरबोर्ड)

## 🌐 ऑनलाइन लीडरबोर्ड

गेम Supabase क्लाउड डेटाबेस में स्कोर सहेजने का समर्थन करता है। सेटअप:

1. https://supabase.com पर प्रोजेक्ट बनाएं
2. `SUPABASE_SETUP.md` से SQL स्क्रिप्ट चलाएं
3. `index.html` में अपनी कुंजियां डालें (`DatabaseManager` क्लास)

विस्तृत निर्देश **SUPABASE_SETUP.md** में

## 📝 विशेषताएं

- प्रक्रियात्मक ग्राफिक्स (कोई बाहरी एसेट नहीं)
- कण प्रणाली (टकराने पर पंख)
- लीडरबोर्ड (localStorage बैकअप)
- रेस्पॉन्सिव डिज़ाइन (100% विंडो)
- Web Audio API के माध्यम से ध्वनि प्रभाव
