# 🐔 Crazy Duck

Παιχνίδι "Κυνήγι παπιών" στο πρόγραμμα περιήγησης με HTML5 Canvas και Vanilla JavaScript.

## 🎮 Πώς να παίξετε

1. Εκκινήστε έναν τοπικό διακομιστή HTTP (απαιτείται για υποστήριξη γλωσσών):
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Python 2
   python -m SimpleHTTPServer 8000
   
   # Node.js (npx)
   npx http-server -p 8000
   
   # PHP
   php -S localhost:8000
   ```
2. Ανοίξτε το `http://localhost:8000` σε οποιοδήποτε σύγχρονο πρόγραμμα περιήγησης
3. Κάντε κλικ στο **"ΕΝΑΡΞΗ"**
4. Στοχεύστε με το ποντίκι και πυροβολήστε με το αριστερό κλικ
5. Συγκεντρώστε τους περισσότερους πόντους σε 90 δευτερόλεπτα!

## 🎯 Τύποι στόχων

| Τύπος | Πόντοι | Περιγραφή |
|-------|--------|-----------|
| 🐔 Κανονική | 10 | Πετάει αργά ευθεία |
| ⚡ Γρήγορη | 20 | Πετάει γρήγορα, ζιγκ-ζαγκ |
| 🪂 Που πέφτει | 30 | Πέφτει με αλεξίπτωτο από πάνω |
| 🛸 ΑΤΙΑ | 50 | Πετάει πολύ γρήγορα |

## 🎮 Έλεγχος

- **Ποντίκι** — στόχευση
- **Αριστερό κλικ** — πυροβολισμός

## 📋 Ρυθμίσεις παιχνιδιού

- **Χρόνος γύρου:** 90 δευτερόλεπτα
- **Πυρομαχικά:** 60 βολές
- **Στόχος:** συγκεντρώστε τους περισσότερους πόντους

## 🛠️ Τεχνολογίες

- HTML5 Canvas
- Vanilla JavaScript (ES6+)
- Web Audio API (συνθετικοί ήχοι)
- CSS3
- Supabase (διαδικτυακή κατάταξη)

## 🌐 Διαδικτυακή κατάταξη

Το παιχνίδι υποστηρίζει αποθήκευση σκορ στη βάση δεδομένων cloud Supabase. Ρύθμιση:

1. Δημιουργήστε ένα έργο στο https://supabase.com
2. Εκτελέστε το σενάριο SQL από το `SUPABASE_SETUP.md`
3. Εισαγάγετε τα κλειδιά σας στο `index.html` (κλάση `DatabaseManager`)

Λεπτομερείς οδηγίες στο **SUPABASE_SETUP.md**

## 📝 Χαρακτηριστικά

- Διαδικαστικά γραφικά (χωρίς εξωτερικά assets)
- Σύστημα σωματιδίων (πούπουλα στο χτύπημα)
- Κατάταξη (αντίγραφο ασφαλείας localStorage)
- Ανταποκριτικός σχεδιασμός (100% παράθυρο)
- Ηχητικά εφέ μέσω Web Audio API
