# 🐔 Crazy Duck

Браузерна гра "Полювання на качок" на HTML5 Canvas та Vanilla JavaScript.

## 🎮 Як грати

1. Запустіть локальний HTTP-сервер (потрібно для підтримки мов):
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Python 2
   python -m SimpleHTTPServer 8000
   
   # Node.js (npx)
   npx http-server -p 8000
   
   # PHP
   php -S localhost:8000
   ```
2. Відкрийте `http://localhost:8000` у будь-якому сучасному браузері
3. Натисніть **"ПОЧАТИ ГРУ"**
4. Прицілюйтеся мишею та стріляйте лівою кнопкою миші
5. Наберіть максимум очок за 90 секунд!

## 🎯 Типи цілей

| Тип | Очки | Опис |
|-----|------|------|
| 🐔 Звичайна | 10 | Летить повільно прямо |
| ⚡ Швидка | 20 | Летить швидко, зигзагом |
| 🪂 Падаюча | 30 | Падає з парашутом зверху |
| 🛸 НЛО | 50 | Летить дуже швидко |

## 🎮 Керування

- **Миша** — прицілювання
- **Ліва кнопка миші** — постріл

## 📋 Параметри гри

- **Час раунду:** 90 секунд
- **Набої:** 60 пострілів
- **Мета:** набрати максимум очок

## 🛠️ Технології

- HTML5 Canvas
- Vanilla JavaScript (ES6+)
- Web Audio API (синтезовані звуки)
- CSS3
- Supabase (онлайн-таблиця лідерів)

## 🌐 Онлайн-таблиця лідерів

Гра підтримує збереження результатів у хмарній базі Supabase. Для налаштування:

1. Створіть проєкт на https://supabase.com
2. Виконайте SQL-скрипт з файлу `SUPABASE_SETUP.md`
3. Вставте ваші ключі в `index.html` (клас `DatabaseManager`)

Детальна інструкція у файлі **SUPABASE_SETUP.md**

## 📝 Особливості

- Процедурна графіка (без зовнішніх ассетів)
- Система частинок (пір'я при влучанні)
- Таблиця лідерів (збереження в localStorage)
- Адаптивний дизайн (100% вікна)
- Звукові ефекти через Web Audio API
